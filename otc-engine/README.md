# GoTradeX OTC Engine

This folder is an isolated service. It does not modify the GoTradeX application.

## Data model

- `otc_prices`: latest OTC price for each pair.
- `otc_candles`: 1-minute OTC OHLC candles for chart history.
- Both rows are explicitly marked `type = OTC`.

## Important market-data rule

OTC prices generated by this service are synthetic. They may be anchored to a real market/reference price, but they are **not** exchange/broker LIVE prices and must never be displayed as LIVE.

The service can use Bybit for BTC/ETH seeds, Twelve Data when a key is supplied, and Frankfurter only as a reference-rate fallback. Frankfurter is not a 2-second real-time Forex feed.

## Run

1. Copy `.env.example` to `.env`.
2. Set `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` as server environment variables.
3. Optionally set `TWELVE_DATA_API_KEY`.
4. Run `npm install`.
5. Run `node index.js`.

Never put the Supabase service-role key in the browser or in the GoTradeX frontend.
